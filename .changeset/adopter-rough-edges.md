Fixes found while switching an existing repository to urzua. A source comment marker whose id is followed by a colon (`Verifies: ADR-12: why`, also `ADR-12::why`) is read as a back-pointer, and a marker that names an id in a form urzua cannot read (`Implements: (ADR-12)`) is counted and listed in an info notice instead of being skipped; the new rule option `unread_markers: report` makes each one a finding, and then `code.dangling-bug-reference` leaves that line to it. `urzua waive --from-report` quotes the findings it drafts in a fenced block, so a drafted waiver no longer reports the dangling ids it quotes. `urzua init` names `effective_requires: [Reason, Expires]` (or `permanent`) as part of the waiver declaration it withholds. `urzua refs refresh` requests pages in parallel when GitHub names the last page (`issue_refs.workers`, default 4, 1 to 16) and follows on serially if that last page still has a next. The harness hooks, the record commands and the session-start check run a binary kept at `.urzua/bin/urzua` only while it is executable, untracked and hashed to the `binary` pin that `urzua harness install` or `update` writes to `.urzua/harness.lock`; `install` adds `.urzua/bin/` to `.gitignore`, `status`, `doctor` and the session-start check report a binary that is unpinned, replaced, tracked or not executable, the post-command check hashes `.urzua/bin`, the lock and the hook files in every repository, and the edit tools refuse an agent's write to `.urzua/bin`.
