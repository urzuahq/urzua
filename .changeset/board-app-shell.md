`urzua board` is drawn as a small web application and gains `--prompt`. The page has a sticky top bar (the urzua mark, search, where the records were read from and when, and the actions), the views as tabs with counts, from 1000 px a sidebar listing the views and every record type the configuration declares with its count, cards for the sections, an empty-state sentence for a section with nothing in it, a footer with the version, `/` to focus the search and `Esc` to clear it, and a light/dark switch that remembers its choice where the browser allows. A row's details open in a panel beside the list on wide screens and inside the row on narrow ones. The page stays one self-contained file with no network request; its icon is an inline `data:` address, and the content security policy allows images only from `data:`. The note about a type that declares no `statuses.progress` moves from the *Under way* section into a new *About this board* panel, which says how each part of the page follows from the configuration and what each type declares; the `board.progress` notice in the JSON is unchanged. A *Build your own view* panel offers a prompt, written from the repository's configuration, to paste into a coding agent so it builds a view from `urzua export --format json`; `urzua board --prompt` prints the same text in a JSON answer (`status`, `prompt`) and writes no file.
