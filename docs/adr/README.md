# Architecture decision records

This directory holds urzua's ADRs, one `ADR-N-slug.md` file each. This index is not a record:
`.urzua/config.yaml` declares it under the `adr` type's `exclude_files`, so no rule examines it
(MILE-150). Read `docs/specs/SPEC-16-the-adr-record-type.md` for what an ADR is.
