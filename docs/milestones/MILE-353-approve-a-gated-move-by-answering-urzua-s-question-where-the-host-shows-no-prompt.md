# 353 — Approve a gated move by answering urzua's question where the host shows no prompt

## What

Under `acceptance.in_session: ask`, an agent's gated move that the host will not prompt for (Claude Code's
`bypassPermissions` and the other modes that show no prompt) is refused with one question urzua wrote; urzua's hooks on
AskUserQuestion record an approving answer; the next edit making the same move with the same proposed content in the
same session is written once with its receipt row (`ADR-105`). The permission prompt stays the route where it is shown.

## Why

The maintainer runs every session in `bypassPermissions`, where in-session approval always refused. His direction,
2026-11-20: "we should support both ... the current way is not working for any of the repos I work on".
