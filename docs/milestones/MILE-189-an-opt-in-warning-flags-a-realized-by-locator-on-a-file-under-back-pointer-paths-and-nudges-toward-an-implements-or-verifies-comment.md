# 189 — An opt-in warning flags a Realized-by locator on a file under back_pointer_paths and nudges toward an Implements or Verifies comment

## What

An opt-in warning rule that flags a `Realized-by` locator naming a file under `back_pointer_paths`, whose message says to move the evidence to an `Implements:` or `Verifies:` comment in that file. It offers no edit action: the comment must exist before the locator goes, and writing it is an edit to a source file, which `ADR-73` handles as an exemption with a reason (as for `embodiment.back-pointer-*`). It is a nudge and not an error: `Realized-by` stays the only option for a path the comment scan cannot reach.

## Why

`ADR-78` item 4 satisfies `RFC-7` section 5, preferring the lighter mechanism: a comment in the file is scanned automatically and cannot go stale away from the code, where a `Realized-by` locator is hand-maintained. No check exists, and `ADR-78` notes that no milestone yet builds it.
