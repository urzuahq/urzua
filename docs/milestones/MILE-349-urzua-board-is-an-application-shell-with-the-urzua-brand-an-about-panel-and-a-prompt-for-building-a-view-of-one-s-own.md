# 349 — urzua board is an application shell with the urzua brand, an About panel and a prompt for building a view of one's own

## What

`urzua board` is drawn as a small web application instead of text on a page, in the urzua brand, and stays the plain default view that works with any configuration. It gains an *About this board* panel that says how each part of the page follows from the configuration, and a *Build your own view* panel, also `urzua board --prompt`, that gives a coding agent a prompt written from the repository's own configuration so it can build a richer view from `urzua export --format json`.

## Why

The maintainer looked at the board of three different repositories on 2026-11-18 and said: "I don't want it to be opinionated with this board. It should just generally work with anything, right? And then maybe there's even a handy thing for saying like, you know, paste this into your agent and then it can dynamically generate a view. Also, maybe we can make it like just a little bit more like it's just like a thing on a page right now. It just needs like maybe a nav bar and like just to feel like a proper web page rather than just like just just the text on the page. Like you know look at like standard modern apps and how they're built. Also, we can use the [urzua] brand guidelines to like give it a bit of design in the [urzua] logo and everything."

The board of `MILE-344` is the plain default and `urzua export` is the input for anything richer (`ADR-103`); this makes the default look like a page a person would use and gives the richer path a starting point, without giving the board an opinion about record types, statuses or workflow. The note about a type that declares no `statuses.progress` was the one place the page spoke about a particular declaration inside a section; it moves to the panel that explains every declaration.
