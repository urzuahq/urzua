# 351 — Rule entries take types: to narrow a rule to record types

## What

Any rule entry in the map form under `rules:` may list `types:`, the declared record types the rule judges (`ADR-104`). A record of another type is not judged by that rule and is counted out of scope; absent, the rule judges every type as before. Using the key in this repository's own `.urzua/config.yaml` (for example `status.children-agreement` narrowed away from specs) is the maintainer's step after release, not part of this milestone.

## Why

`status.children-agreement` applies to every type that declares `part_of`, and in this repository only specs do, which are living documents the rule does not fit; there was no way to enable a rule for some types only. The maintainer's direction, 2026-11-19: "You should be able to set it. The rules per record type, right? Like, that should be a thing for sure."
