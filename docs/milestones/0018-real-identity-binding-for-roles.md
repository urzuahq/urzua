# 0018 — Real identity binding for roles

> Status: Planned
> Stable-Id: 01M1Y5JNM6KSG8K1XBT7YMV9FB

## What

Resolve Author/Reviewer/Decider to a real account (GitHub/SSO) instead of free-text names.

## Why

A free-text name silently rots when the person leaves -- the same accountability gap RFC-0002/ADR-0031 already closed for fix --apply's identity, not yet extended to header role fields.
