# 255 — Fields may be read from a section, and identity need not be an integer

## What

Read a header field from a named section (a `## Status` section, as in the common ADR style), and allow identity that is not prefix plus integer: a date, or a file name with no number.

## Why

the audit of 2026-11-15's extensibility experiments found that `init` refuses a corpus in the most common ADR style because no file has a header, a `## Status` section is never read as status, and date-based or numberless names are refused or cannot be generated by `new`.

## Done means

- A type that declares a section as the source of a field reads the field from it, and `init` proposes that for a corpus written that way.
- A type that declares date-based identity has its records identified, ordered and created by `urzua new`.
- `urzua new` in a corpus numbered with leading zeros writes the same width, and its heading follows the corpus's existing form.
