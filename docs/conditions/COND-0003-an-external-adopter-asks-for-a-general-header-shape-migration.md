# COND-0003 — An external adopter asks for a general header-shape migration

## Signal

Met when a real external adopter asks for `urzua migrate header-shape` to convert their corpus to `yaml-frontmatter`. The ask is written down in a record (a milestone, an ADR or an RFC that names the adopter and the ask), and `Met-by` names that record. This repository's own conversion, which is done, does not count, and neither does a hypothetical adopter.

## Why this is a condition

`MILE-23` waited on this in prose (`Blocked-on: a real external adopter asking for it`).
